前端调试检查

检查前端代码是否已加载最新版本

步骤1: 打开浏览器控制台

按 F12 打开开发者工具，切换到 Console 标签

步骤2: 打开选股器页面

点击下方按钮打开选股器页面：

步骤3: 检查控制台输出

在控制台中应该看到类似这样的日志：

🔍 StockScreenerPage - store状态变化 (时间戳: ...):
  isExecuting: false
  currentResults长度: 0
  executionJobId: null
  store对象: {...}

如果看到这些日志，说明前端代码已加载最新版本。

步骤4: 执行选股测试

在选股器页面点击"执行选股"按钮，然后在控制台中应该看到：

🔍 executeScreening开始: selectedStrategyId=default_composite
🔍 API响应 (时间戳: ...):
  status: completed
  job_id: exec_...
  results长度: 44
🔍 API直接返回结果，更新store状态
🔍 store状态已更新: currentResults.length=44

步骤5: 如果看不到调试日志

如果看不到上述调试日志，说明前端代码没有重新加载：

  1. 强制刷新页面: 按 Ctrl+Shift+R (Windows/Linux) 或 Cmd+Shift+R (Mac)
  2. 清除浏览器缓存: 在开发者工具中，右键刷新按钮 → "清空缓存并硬性重新加载"
  3. 重启前端开发服务器: 
    cd frontend
npm run dev

步骤6: 直接测试API

点击下方按钮测试API是否工作：

步骤7: 检查React组件

如果有React DevTools扩展：

  • 查看 StockScreenerPage 组件的props
  • 检查 ResultsFormView 组件是否接收到 results 数组
  • 检查组件是否重新渲染
