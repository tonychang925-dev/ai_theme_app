# 测试报告技能（Test Report Protocol - Production Final ZH）

本技能用于生成**结构化、可审计、可追溯的测试报告**。

它扮演角色： - QA负责人 - 质量评估官 - 风险审计人

目标：
输出一个客观、可验证、可追溯的测试报告，用于里程碑评审或发布决策。

------------------------------------------------------------------------

# 0. 必需输入

生成测试报告前必须明确：

1. Milestone名称
2. Phase编号
3. 测试范围
4. 执行命令列表
5. 读取相关测试用例路径：
  - docs/test_cases/<level>/<filename>.md 
  - docs/project_control/TEST_CASE_SPEC.md 
6. 是否包含性能/压力测试
7. 风险等级（Low / Medium / High）

如信息不足 → 必须先请求补充。

------------------------------------------------------------------------

# 1. 必须生成文件

docs/project_control/TEST_REPORT.md

不得只输出摘要。

------------------------------------------------------------------------

# 2. 测试报告结构

# 测试报告

## 1. 基本信息

-   Milestone:
-   Phase:
-   测试负责人:
-   执行时间:
-   风险等级:

------------------------------------------------------------------------

## 2. 测试范围

-   覆盖模块
-   覆盖功能点
-   未覆盖范围（必须列出）

------------------------------------------------------------------------

## 3. 执行命令记录

  序号   命令   执行结果   关键输出
  ------ ------ ---------- ----------

必须记录： - 单元测试命令 - Lint命令 - 类型检查命令（如适用） -
构建命令（如适用）

------------------------------------------------------------------------

## 4. 测试结果统计

  项目       数值
  ---------- ------
  总用例数   
  通过数     
  失败数     
  跳过数     
  通过率     

------------------------------------------------------------------------

## 5. 性能结果（如适用）

-   P50延迟:
-   P95延迟:
-   最大响应时间:
-   内存占用:
-   CPU峰值:

------------------------------------------------------------------------

## 6. 缺陷记录

| 缺陷ID \| 严重级别 \| 描述 \| 当前状态 \|

严重级别： - P0 阻断 - P1 关键 - P2 次要 - P3 低优先

------------------------------------------------------------------------

## 7. 风险评估

### 当前残余风险

-   技术风险
-   性能风险
-   数据一致性风险
-   可扩展性风险

### 风险等级判定

Low / Medium / High

说明理由。

------------------------------------------------------------------------

## 8. 回归影响评估

-   影响模块
-   影响接口
-   是否存在行为变化
-   是否需要额外回归测试

------------------------------------------------------------------------

## 9. 发布建议

必须二选一：

-   ✅ 建议通过（Ready for release）
-   ❌ 不建议通过（Requires fix）

若不通过： 必须列出阻断项。

------------------------------------------------------------------------

# 3. 强制规则

-   不允许模糊描述
-   不允许"基本正常"
-   不允许省略命令输出
-   不允许跳过失败用例说明
-   不允许忽略未覆盖范围

------------------------------------------------------------------------

# 4. 行为规范

该技能必须：

-   客观
-   保守
-   基于证据
-   可追溯
-   不乐观推断

------------------------------------------------------------------------

# End of Test Report Protocol
