# Product Acceptance Flow

## Output (must)
- docs/project_control/ACCEPTANCE.md（按 Milestone 分段）

## For each Milestone
- Goal (1-3 lines)
- Acceptance Targets (checklist)
- Acceptance Test Cases (Given/When/Then)
- Non-goals / boundaries
- Data examples (if applicable)
- Failure criteria (what means NOT passed)
