浏览器控制台调试指南

解决"0 条记录"问题

操作步骤：

1. 打开浏览器开发者工具

按 F12 或右键点击页面选择"检查"

2. 切换到Console标签

查看是否有JavaScript错误

3. 执行选股操作

在选股器页面点击"执行选股"按钮

4. 观察控制台输出

应该看到类似这样的日志：

🔍 executeScreening开始: selectedStrategyId=default_composite
🔍 API响应: status=completed results.length=44
🔍 API直接返回结果，更新store状态
🔍 store状态已更新: currentResults.length=44
🔍 StockScreenerPage - store状态变化:
  isExecuting: false
  currentResults长度: 44
  executionJobId: exec_xxxxxx

5. 检查Network标签

查看API请求是否成功：

  • 找到 /api/stock-screener/execute 请求
  • 检查Response标签查看API返回的数据
  • 确认 status: "completed" 和 results 数组不为空

6. 检查React组件

如果有React DevTools扩展：

  • 查看 StockScreenerPage 组件的props
  • 检查 currentResults 是否更新
  • 检查组件是否重新渲染

常见问题诊断：

问题1: 没有看到调试日志

可能原因：前端代码没有重新加载

解决方案：

  1. 强制刷新页面：Ctrl+Shift+R (Windows/Linux) 或 Cmd+Shift+R (Mac)
  2. 清除浏览器缓存
  3. 重启前端开发服务器

问题2: 看到API错误

可能原因：后端服务问题

检查：

  1. 后端服务是否运行：http://localhost:8003/api/stock-screener/strategies
  2. API响应状态码
  3. 控制台错误信息

问题3: store更新但页面不显示

可能原因：React渲染问题

检查：

  1. React组件是否正确订阅store
  2. 组件是否重新渲染（查看React DevTools）
  3. 是否有其他错误阻止渲染

问题4: 仍然显示"0 条记录"

可能原因：多个问题叠加

执行完整检查：

  1. 打开 realtime_store_debug.html 监控store状态
  2. 运行 final_verification_test.html 验证系统功能
  3. 检查所有测试是否通过

快速测试命令：

在浏览器控制台中直接运行这些命令测试API：

// 测试API是否工作
fetch('http://localhost:8003/api/stock-screener/execute', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        strategy_id: 'default_composite',
        trade_date: '2026-04-10',
        limit: 3,
        enable_llm_review: false,
        llm_top_k: 3
    })
})
.then(r => r.json())
.then(data => console.log('API响应:', data))
.catch(err => console.error('API错误:', err));

// 检查store状态（如果store是全局的）
if (window.store) {
    console.log('store状态:', {
        isExecuting: window.store.isExecuting,
        currentResults长度: window.store.currentResults.length,
        currentResults: window.store.currentResults
    });
}

下一步：

根据控制台输出确定问题所在：

  1. 如果看到调试日志和API成功响应 → 前端显示问题
  2. 如果看到API错误 → 后端服务问题
  3. 如果没有调试日志 → 前端代码没有加载
  4. 如果store更新但页面不显示 → React渲染问题

打开 选股器页面 开始调试。
