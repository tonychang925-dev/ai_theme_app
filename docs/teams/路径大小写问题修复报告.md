# 路径大小写问题修复报告

## 问题诊断
**诊断时间**: 2026-04-12
**问题现象**: "Error writing file"错误间歇性出现，特别是在团队协作场景

**根本原因**: macOS路径大小写不一致
- 实际目录: `/Users/admin/Desktop/ai_theme_app` (大写D)
- Shell输出: `/Users/admin/desktop/ai_theme_app` (小写d)
- 环境变量使用小写路径，导致Claude Code路径解析失败

## 修复方案

### 1. 修复Claude启动脚本 (`claude`)
```bash
# 路径规范化函数
normalize_path() {
  local path="$1"
  if command -v realpath >/dev/null 2>&1; then
    realpath "$path" 2>/dev/null || echo "$path"
  else
    (cd "$path" && pwd -P) 2>/dev/null || echo "$path"
  fi
}

# 强制规范化环境变量路径
if [ -n "${AI_THEME_APP_ROOT:-}" ]; then
  AI_THEME_APP_ROOT="$(normalize_path "$AI_THEME_APP_ROOT")"
else
  AI_THEME_APP_ROOT="$PROJECT_DIR"
fi
```

### 2. 修复团队环境变量传递 (`spawnUtils.ts`)
添加`AI_THEME_APP_ROOT`和`PROJECT_ROOT`到队友环境变量传递列表：
```typescript
const TEAMMATE_ENV_VARS = [
  // ... 其他变量
  'AI_THEME_APP_ROOT',
  'PROJECT_ROOT',
]
```

### 3. 修复Claude Code核心路径解析
- `src/utils/path.ts`: `expandPath()`优先使用`AI_THEME_APP_ROOT`
- `src/utils/cwd.ts`: `getCwd()`优先返回`AI_THEME_APP_ROOT`

## 技术原理

### macOS路径大小写问题
- HFS+/APFS文件系统可能不区分大小写
- Shell命令`pwd`可能返回小写路径
- `realpath`返回实际物理路径（正确大小写）
- 路径解析必须使用一致的大小写格式

### 修复策略
1. **源头修正**: 在环境变量设置时规范化路径
2. **传播保障**: 确保环境变量传递给所有子进程
3. **核心支持**: 修改Claude Code路径解析函数
