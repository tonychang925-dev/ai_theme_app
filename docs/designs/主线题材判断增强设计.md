# 主线题材判断增强设计文档

## 1. 概述

基于PDF交易体系理论，增强主线题材判断的逻辑维度和市场维度评估，提升选股准确性。

## 2. 设计目标

### 2.1 逻辑维度增强
- **新颖度评分**：评估题材的新颖程度
- **时机评分**：评估市场环境是否有利于题材发酵
- **影响广度评分**：评估题材的影响范围和深度

### 2.2 市场维度增强
- **资金流入持续性**：评估资金持续流入情况
- **机构参与度**：评估机构资金的参与程度
- **散户关注度**：评估散户关注热度

## 3. 数据源分析

### 3.1 现有数据源
1. **theme_mainline_judgement** - 主线判断基础表
2. **market_environment_judgement** - 市场环境评估
3. **money_flow_enhanced** - 资金流数据
4. **subject_stock_map** - 题材-股票映射
5. **subject_rank_daily** - 题材热度排名

### 3.2 需要新增的数据
1. **题材首次出现时间** - 用于新颖度计算
2. **题材行业分布** - 用于影响广度计算
3. **社交媒体热度** - 用于散户关注度计算

## 4. 技术方案

### 4.1 方案一：扩展现有表（推荐）
在`theme_mainline_judgement`表中添加新字段：
- `novelty_score` (NUMERIC(6,2)) - 新颖度得分
- `timing_score` (NUMERIC(6,2)) - 时机得分
- `influence_score` (NUMERIC(6,2)) - 影响广度得分
- `capital_persistence_score` (NUMERIC(6,2)) - 资金持续性得分
- `institution_participation_score` (NUMERIC(6,2)) - 机构参与度得分
- `retail_attention_score` (NUMERIC(6,2)) - 散户关注度得分

**优点**：
- 查询简单，无需多表关联
- 与现有系统兼容性好
- 数据更新同步

**缺点**：
- 表结构变得臃肿
- 需要修改现有数据构建脚本

### 4.2 方案二：创建新表
创建`theme_mainline_enhanced_judgement`表，包含增强字段，通过(trade_date, subject_key)与主表关联。

**优点**：
- 保持原表结构不变
- 模块化设计，便于独立维护

**缺点**：
- 增加查询复杂度
- 需要维护数据一致性

## 5. 评分算法设计

### 5.1 新颖度评分 (0-30分)
```
novelty_score = base_score + media_score + concept_score

base_score: 基于首次出现时间（0-15分）
  - 首次出现 <= 7天: 15分
  - 首次出现 <= 30天: 10分
  - 首次出现 <= 90天: 5分
  - 首次出现 > 90天: 0分

media_score: 媒体报道频率（0-10分）
  - 高频报道（日均有报道）: 10分
  - 中频报道（周均有报道）: 6分
  - 低频报道（月均有报道）: 3分
  - 无报道: 0分

concept_score: 概念新颖性（0-5分）
  - 全新概念/技术: 5分
  - 现有概念延伸: 3分
  - 传统概念: 1分
```

### 5.2 时机评分 (0-25分)
```
timing_score = market_env_score + sentiment_score + gap_score

market_env_score: 市场环境（0-10分）
  - 基于market_environment_judgement.market_health_score
  - 评分转换：健康评分 * 0.1

sentiment_score: 市场情绪（0-10分）
  - 涨停家数 > 50: 10分
  - 涨停家数 20-50: 7分
  - 涨停家数 10-20: 4分
  - 涨停家数 < 10: 1分

gap_score: 题材荒间隙（0-5分）
  - 距离上个主线题材结束 > 30天: 5分
  - 距离上个主线题材结束 15-30天: 3分
  - 距离上个主线题材结束 < 15天: 1分
```

### 5.3 影响广度评分 (0-25分)
```
influence_score = stock_count_score + industry_score + policy_score

stock_count_score: 关联股票数量（0-10分）
  - 股票数 > 50: 10分
  - 股票数 20-50: 7分
  - 股票数 10-20: 4分
  - 股票数 < 10: 1分

industry_score: 行业覆盖面（0-10分）
  - 行业数 > 5: 10分
  - 行业数 3-5: 7分
  - 行业数 2-3: 4分
  - 行业数 1: 1分

policy_score: 政策级别（0-5分）
  - 国家级政策: 5分
  - 省级/部委级: 3分
  - 行业/地方级: 1分
  - 无政策支持: 0分
```

### 5.4 市场维度增强评分

#### 5.4.1 资金流入持续性 (0-15分)
```
capital_persistence_score = flow_trend_score + flow_amount_score

flow_trend_score: 流入趋势（0-8分）
  - 连续5日净流入: 8分
  - 连续3日净流入: 5分
  - 净流入不稳定: 2分
  - 净流出: 0分

flow_amount_score: 流入金额（0-7分）
  - 日均净流入 > 10亿: 7分
  - 日均净流入 1-10亿: 4分
  - 日均净流入 < 1亿: 1分
```

#### 5.4.2 机构参与度 (0-10分)
```
institution_participation_score = seat_score + research_score

seat_score: 龙虎榜机构席位（0-6分）
  - 近期有机构席位出现: 基于出现频率评分

research_score: 机构调研（0-4分）
  - 近期有机构调研: 4分
  - 无调研: 0分
```

#### 5.4.3 散户关注度 (0-10分)
```
retail_attention_score = search_score + community_score

search_score: 搜索指数（0-5分）
  - 搜索指数高位: 5分
  - 搜索指数中位: 3分
  - 搜索指数低位: 1分

community_score: 社区讨论（0-5分）
  - 讨论热度高: 5分
  - 讨论热度中: 3分
  - 讨论热度低: 1分
```

## 7. 接口变更

### 7.1 数据模型变更
```python
# theme_mainline_judgement 表新增字段
novelty_score: float  # 新颖度得分
timing_score: float   # 时机得分
influence_score: float # 影响广度得分
capital_persistence_score: float  # 资金持续性得分
institution_participation_score: float  # 机构参与度得分
retail_attention_score: float  # 散户关注度得分
```

### 7.2 选股器评分变更
```python
# 新的主线评分逻辑
def score_mainline_dimension_enhanced(context):
    # 原有评分（80分）
    base_score = event_chain_score + market_recognition_score + mainline_stability_score
    
    # 新增逻辑维度（80分 * 0.3 = 24分）
    logic_score = (novelty_score + timing_score + influence_score) * 0.3
    
    # 新增市场维度（80分 * 0.2 = 16分）
    market_enhanced_score = (capital_persistence_score + institution_participation_score + retail_attention_score) * 0.2
    
    total_score = min(base_score + logic_score + market_enhanced_score, 100)
    return total_score
```

## 8. 性能考虑

1. **计算复杂度**：新增维度会增加计算时间，需异步处理
2. **数据存储**：新增字段增加存储空间，需评估影响
3. **查询性能**：可能影响查询速度，需添加索引
