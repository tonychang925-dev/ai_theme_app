> 版本: 1.0
> 日期: 2026-05-27
> 状态: v2.2 影子观察期

---

## 一、投资理念

### 1.1 什么是弱转强

龙头股在高位分歧后，出现"看似走弱"（大阴线/烂板/冲高回落），但次日通过强势竞价或盘中反转，重新夺回市场话语权，完成从"弱势"到"强势"的转化。

**核心逻辑**：资金主力洗盘震仓后再次合力进攻，往往意味着二波行情或高度延伸。

### 1.2 策略本质

```
不是奖励"已经强"
而是识别"刚从弱变强，且尚未过度拉升"
```

| 误区 | 正确 |
|------|------|
| 越强越好 | 刚转强、未追高最好 |
| 高分=追高确认 | 高分反而可能是趋势末端 |
| platform_break 是买点 | platform_break 是追高诊断因子 |

### 1.3 三种弱转强形态

| 类型 | 判断依据 | 数据依赖 |
|------|---------|---------|
| **竞价弱转强** | 9:25 竞价确认 A/B 级 + 资金净流入 | 竞价快照 + 五档盘口 |
| **早盘弱转强** | 放量拉升 + 分时均线上方 | 分钟状态层 + VWAP |
| **盘中弱转强** | 弱于大盘→强于大盘 / 突破分时平台 | 分钟状态 + 指数对比 |

## 二、技术架构

### 2.1 两阶段设计

```
T日盘后（D1 候选）:
  strong_stock_watch_pool → BuildW2SCandidate
  → weak_to_strong_candidate_pool
  条件: pct_chg ≤ -1%, limit_up=false, 支撑有效

T+1日（D2 确认 + 盘中观察）:
  9:25 竞价 → W2SAuctionScorer → A/B/C/X
         → 资金流向过滤（五档盘口 tradeFive）
  9:30-15:00 盘中 → v2.2 Scorer → early_turn/turn_strong
         → 支撑位监控 → near/touch/break/recover
```

### 2.2 核心组件

| 组件 | 文件 | 功能 |
|------|------|------|
| D1 候选池 | `weak_to_strong_candidate_pool` | 盘后选股，max 10 只/天 |
| D2 竞价评分 | `w2s_auction_scorer.py` | 6 信号 + hard reject |
| D2 确认 | `w2s_confirm_service.py` | A/B/C/X 确认 |
| 资金流向 | `normalizers.py:_parse_trade_five` | 五档盘口 ASK/BID 失衡 |
| 分钟状态层 | `intraday_minute_state_builder.py` | OHLCV + VWAP + 相对大盘 |
| v2.2 评分器 | `w2s_intraday_alert_service_v2.py` | 6 维评分 + turn_strong 门禁 |
| 支撑检测 | `kline_break_detector.py` | near/touch/break/recover |
| 统一管线 | `w2s_unified_alert_service.py` | 竞价+盘中统一输出 |

### 2.3 数据流

```
弱转强候选池 D1
  ├─→ 竞价采集 (9:15-9:26)
  │     ├─ stock/realtime → 价格 + 五档盘口
  │     └─ pre_market_auction_snapshot
  ├─→ 竞价确认 (9:25)
  │     ├─ W2SAuctionScorer → A/B/C/X
  │     └─ 资金流向过滤 → outflow → 降级
  ├─→ 盘中分钟状态 (9:30-15:00)
  │     ├─ jyhf_stock_quote_snapshot → OHLCV 聚合
  │     ├─ VWAP + 相对大盘 + 30m 平台
  │     └─ intraday_stock_minute_state
  └─→ 统一告警
        ├─ stream:w2s:alerts
        ├─ SSE → 前端弱转强观察区
        └─ w2s_intraday_alert_log (影子日志)
```

## 四、回测发现

### 4.1 因子有效性排序（BT-3b, 819 signals, 2 days）

| 因子 | true avg_30m | false avg_30m | 差值 | 结论 |
|------|-------------|--------------|------|------|
| **relative_strength_cross_zero** | -0.25% | -0.50% | **+0.25%** | ✅ 最佳 |
| above_vwap_cross_up | -0.68% | -0.46% | -0.22% | ❌ 假突破 |
| amount_acceleration | -0.68% | -0.38% | -0.30% | ❌ 放量滞涨 |
| platform_break_30m | -1.34% | — | — | ❌ 追高 |

### 4.2 核心发现

1. **"越强越追高"**: v1 A 级 avg_30m=-0.94%，platform_break=-1.34%
2. **C 级反而最稳**: avg_30m=-0.41%，早期低位触发优于高分确认
3. **cross_zero 唯一正贡献**: 弱转强本质 = "从弱于大盘转强于大盘"
4. **VWAP 刚站上可能是假突破**: cross_up=-0.22%，需 rel_cross_zero 确认

### 4.3 资金流向验证（5/27 竞价）

| 股票 | 竞价评分 | 盘口 | 结果 |
|------|---------|------|------|
| 同有科技 | A (85.55) | **流出** -6,600 股 | → C（降级） |
| 万润科技 | A (79.30) | 未知 | A（缺数据放行） |

## 五、关键发现总结

1. **竞价确认是有效的第一道筛选**（D2 A/B 级 vs C/X 级有区分度）
2. **资金流向过滤必要且有效**（同有科技 A→C 降级验证了流出=假强势）
3. **盘中追高是最大陷阱**（platform_break/above_vwap_high 均为负贡献）
4. **刚转强拐点比持续强势更有价值**（early_turn > turn_strong）
5. **分钟状态层是基础**（VWAP 单位修复后整个体系才可信）
6. **candidate_date 错位导致竞价采集空跑**（已修复为昨天日期）

## 六、展望

### 6.1 短期（5 个交易日观察期）

- 每日自动复盘：`build_w2s_intraday_shadow_report.py`
- 5 日滚动评估：`build_w2s_intraday_shadow_rolling_report.py`
- 核心指标：v2.2 early_turn 持续性、cross_zero 稳定性、漏报特征

### 6.2 中期（20 个交易日后）

- P1-I-4j：v2.2 观察期复盘结论
- v2.3 校准：基于 20 日统计调整 early_turn 阈值
- 全市场覆盖评估：当前仅候选池 + 强势股

### 6.3 长期（60 个交易日后）

- 策略规则固化：可复用的因子权重
- 前端信号升级：观察→策略参考（仍非买入指令）
- 分钟状态层扩展：分时平台突破算法的改进

### 6.4 暂不纳入

- 自动交易/买卖指令
- 全市场实时扫描
- L2 盘口/逐笔成交
- 秒级高频信号
