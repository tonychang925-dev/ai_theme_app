# 旧链逐项复刻矩阵（2026-05-07）

## 0. 当前结论

新链必须先复刻旧链生产逻辑，再谈工程化增强。当前已确认 Layer C 原新链主流程：

```text
subject_stock_pool 全量
→ Universe
→ Seed
→ Refresh
→ Admission
→ Prune
→ Promote
```

不是旧链弱转强正式入口复刻。该流程已降级为 shadow / diagnostic。

正式候选入口已通过 `SPS_LAYER_C_INPUT_MODE=legacy_watch_pool` 切回旧链口径：

```text
strong_stock_watch_pool / strong_stock_watch_history
→ active / weakening
→ formal / observe_only
→ W2S D 层旧链硬门
→ HARD_MAX_CANDIDATES=10
```
