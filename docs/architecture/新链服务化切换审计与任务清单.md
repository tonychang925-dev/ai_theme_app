## 六、架构纪律重申（不变）

1. **新链不得直接 SQL 操作数据库**：所有读写必须通过 `StockReadPort / SnapshotWritePort / AlgorithmStateWritePort / DatabaseGateway`
2. **Domain 只做业务算法**：不得引入 asyncpg、SQL、gateway
3. **新代码禁止 subprocess**：所有脚本调用替换为 Job/Service Runner
4. **Collection Pipeline 统一走 Runner 协议**：不再新增 `CollectionCommand`
5. **新 Runner 必须通过 Container/Port 注入依赖**，不自行创建 DB 连接
