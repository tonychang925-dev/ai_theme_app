## 七、架构纪律（已冻结）

1. **Application 只编排，不做规则** — 所有评分/门禁在 domain/services
2. **Domain 只算业务，不依赖 SQL/gateway** — 无 asyncpg/SQL字符串
3. **所有读写经 DatabaseGateway 显式方法** — StockReadPort/SnapshotWritePort/StockEventPort
4. **无 fallback/静默降级** — DB真源缺失→fail-fast；所有fallback代码已删除
5. **前端/BFF 禁止直连 DB** — 生产路径违例已清零
6. **禁止新增启发式评分/补丁字段** — 本轮修复期间已冻结
