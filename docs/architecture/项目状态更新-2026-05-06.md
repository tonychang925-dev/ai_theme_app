### 2.6 Layer C 双路径入池语义修正完成

这是今天最重要的架构语义纠偏之一。

旧错误理解：

```text
两连板不能绕过 Layer A/B 进入强势股池。
```

修正后定义：

```text
两连板不能反向确认题材主线身份，
但两连板 / 三天两板 / 近7日多次涨停必须无条件进入强势股观察池。
```

Layer C 现在固定为双路径：

1. **主线强势路径**
   - `identity_status=confirmed`
   - `is_main_theme=true`
   - `final_mainline_alive=true`
   - `entry_path=mainline_strong`

2. **独立龙头路径**
   - 两连板 / 三天两板 / 近 7 日多次涨停
   - 可突破 Seed `rank<=30` 门禁
   - 进入强势股观察池 observe 路径
   - `entry_path=independent_leader`
   - `identity_scope=independent_stock_signal`
   - 不回写 Layer A/B，不确认题材主线

新增实现：

| 文件 | 说明 |
|---|---|
| `domain/services/strong_watch_preseed_gene_enricher.py` | Seed 前识别 `strong_gene_seed / two_board_entry / recent_multi_limitup / three_days_two_boards` |
| `domain/services/strong_watch_seed_service.py` | rank>30 时允许 `strong_gene_seed` 或 `two_board_entry` 突破 Seed gate |
| `domain/services/strong_watch_universe.py` | 独立龙头路径进入 observe，不进入 formal，不回写 A/B |

## 八、架构纪律（继续冻结）

1. **新链不得直接 SQL 操作数据库**：所有读写必须通过 `StockReadPort / SnapshotWritePort / AlgorithmStateWritePort / DatabaseGateway`。
2. **Domain 只做业务算法**：不得引入 asyncpg、SQL、gateway。
3. **Layer B DB truth source 不允许 fallback**：`theme_cycle_evidence_daily` 缺失必须 fail-fast。
4. **两连板只确认个股强势观察资格，不确认题材主线身份**。
5. **独立龙头路径不得回写 Layer A/B 真源**。
6. **不要为单票加特例**：维科/联德必须通过通用逻辑解决。
7. **不要先调阈值**：先用 replay matrix / candidate miss / Layer B explain 定位失败原因。
8. **observe_candidates 不等同 formal top_candidates**：观察层只做跟踪与次日确认准备。
