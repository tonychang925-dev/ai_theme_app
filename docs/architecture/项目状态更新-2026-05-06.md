1. **主线强势路径**
   - `identity_status=confirmed`
   - `is_main_theme=true`

   - 两连板 / 三天两板 / 近 7 日多次涨停
   - 可突破 Seed `rank<=30` 门禁
   - 进入强势股观察池 observe 路径
   - `entry_path=independent_leader`
   - `identity_scope=independent_stock_signal`
   - 不回写 Layer A/B，不确认题材主线

### 2.7 StrongWatch 生命周期机制完成

**入池、延续、续命、剔除**四条链路全部就绪。

#### 入池（双路径）

1. **主线强势路径**：`identity_confirmed + is_main_theme + cycle_alive` → `entry_path=mainline_strong`
2. **独立龙头路径**：`strong_gene_seed=True`（两连板/三天两板/近7日多次涨停）→ `entry_path=independent_leader`，可突破 Seed `rank≤30` 门禁，但不回写 Layer A/B

#### 延续（RollForward + Baseline Merge）

- `StrongWatchRollForwardService`：prior active/weakening → `watch_age_days+1`，`watch_status=pending_refresh`
- `StrongWatchService.baseline_merge`（已修复）：使用 RollForward 递增后的 `watch_age_days/weak_days`；当 Refresh 触发 renewal reset 时保留重置值

#### 续命（六类通用强信号）

`StrongWatchRefreshService` 中 `renewal_signal` 已从 `two_board_entry` 专属升级为六类通用信号：

| 优先级 | renewal_reason | 触发条件 |
|:---:|------|------|
| 1 | `two_board_renewal` | 两连板/三天两板/近7日多次涨停 |
| 2 | `limit_up_renewal` | 当日涨停 (pct ≥ 9.5%) |
| 3 | `recent_multi_limitup_renewal` | 近7日涨停 ≥ 2次 |
| 4 | `prior7_multi_limitup_renewal` | prior7 涨停 ≥ 2天 |
| 5 | `strong_rebound_renewal` | 涨幅 ≥ 5% + 支撑 ≥ 50 |
| 6 | `watch_score_reactivation` | watch_score ≥ 72 |

续命触发时：`watch_age_days=1, weak_days=0, renewal_signal=True, watch_age_reset=True`。

#### 剔除（7日窗口 + 结构破坏）

- `StrongWatchPruneService.WATCH_WINDOW_TRADE_DAYS = 7`
- `watch_age_days > 7` → `DELAYED_PRUNE_WATCH_WINDOW_EXPIRED`
- `fade_confirmed` → 立即剔除
- 无支撑+无涨停基因 → 立即剔除

#### 诊断字段

`labels_json` 新增：
- `renewal_signal` / `renewal_reason` / `watch_age_reset`
- `watch_age_days` / `weak_days`（已修复 metadata→attribute 读取）

## 八、架构纪律（继续冻结）

1. **新链不得直接 SQL 操作数据库**：所有读写必须通过 `StockReadPort / SnapshotWritePort / AlgorithmStateWritePort / DatabaseGateway`。
2. **Domain 只做业务算法**：不得引入 asyncpg、SQL、gateway。
3. **Layer B DB truth source 不允许 fallback**：`theme_cycle_evidence_daily` 缺失必须 fail-fast。
4. **两连板只确认个股强势观察资格，不确认题材主线身份**。
5. **独立龙头路径不得回写 Layer A/B 真源**。
6. **不要为单票加特例**：维科/联德必须通过通用逻辑解决。
7. **不要先调阈值**：先用 replay matrix / candidate miss / Layer B explain 定位失败原因。
8. **observe_candidates 不等同 formal top_candidates**：观察层只做跟踪与次日确认准备。
