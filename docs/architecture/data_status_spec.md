# 弱转强 P0 协议：数据状态规范（data_status_spec）

版本：`data_status_spec.v1`

## 1. 目标

在盘前确认中区分“信号质量问题”和“数据质量问题”，避免把数据缺失误判为策略失败。

## 2. 状态定义

1. `ok`：关键数据完整且时效正常
2. `partial`：存在非关键字段缺失，可降级评分
3. `delayed`：关键窗口数据延迟，默认转 `X` 或仅观察
4. `missing`：关键窗口数据缺失，直接 `X`

## 3. 关键字段

以下字段任一缺失，不能判定为 `ok`：

1. 竞价时间窗：9:20-9:25 连续片段
2. 最后一分钟（9:24-9:25）成交量与价格片段
3. 候选池反查信息：`candidate_id`、`stock_id`
4. 板块联动最小字段：板块红盘率或等价强弱指标

## 4. 判定规则

1. 若关键字段齐全，且数据延迟 `<= 2000ms`，判定 `ok`
2. 若关键字段齐全，但数据延迟 `> 2000ms`，判定 `delayed`
3. 若关键字段部分缺失，且不足以完成确认，判定 `missing`
4. 若关键字段齐全但非关键字段缺失，判定 `partial`

## 5. 与分级联动

1. `ok`/`partial`：允许输出 A/B/C（`partial` 需附降级说明）
2. `delayed`/`missing`：默认输出 `X`，不计入策略效果统计

## 6. 必填审计字段

1. `data_status`
2. `data_latency_ms`
3. `source_snapshot_id`
4. `mapping_warnings`（可为空数组）

## 7. 验收清单（P0 Gate）

1. 所有盘前信号记录均具备 `data_status`
2. `X` 级样本可按 `delayed/missing` 聚类统计
3. 不允许在数据缺失情况下输出 A/B 正式信号
