# 昊哥情绪指标：转录数据与复现脚本

| 文件 | 内容 |
|---|---|
| `haoge_data.py` | 样本内 18 个交易日（6/24–7/17）：大盘势能 5 项、情绪动能 6 项的原始读数、昊哥公布的合成值与颜色（转录自昊哥复盘表格） |
| `haoge_data_oos.py` | 7/31–9/29 共 42 个交易日的同类读数（转录自 12 篇复盘中的表格） |
| `reproduce.py` | 样本内复现：按颜色推断的固定阈值逐项 ±2 投票，与昊哥公布值对照 |
| `oos.py` | V1（样本内冻结）与 V2（修订）阈值在样本内、7/31–9/29 上的复现 |

运行（不依赖第三方包，不访问数据库或网络）：

```bash
cd docs/strategy_research/haoge_data
python3 reproduce.py
python3 oos.py
```
