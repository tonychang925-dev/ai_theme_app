## 0. 通用约定

| 项 | 约定 |
|---|---|
| 命名 | 保留来源名 `source_metric_name`。内部规范名：`market_power_vote` [-10, +10]、`emotion_momentum_vote` [-12, +12]、`emotion_composite = market_power_vote + emotion_momentum_vote` [-22, +22]。**`emotion_composite` ≠ `market_emotion_state`**；昊哥表里叫“周期”的那一项，只是来源名 |
| 数据状态 | 每个值必须是 MEASURED、ESTIMATED 或 MISSING 之一。ESTIMATED 和 MISSING 不参与投票，对应的投票项记为 UNKNOWN，该块的合计也记为 UNKNOWN |
| 两个范围不同 | 大盘势能这一块看起来是**全市场**口径；情绪动能这一块，他的表头明确写着“情绪动能（**主板**）”，所以 E01–E06 的标的范围默认是主板 🔶 |
| 观察时点 | 收盘（15:00 之后），T 日数据；“昨日”指上一个交易日 |
| 已知异常 | 7/10 亏钱效应比 3.94 被标为有利，与阈值矛盾，标记为 `SOURCE_ANOMALY`，**不为这一天单独打补丁** |

## 5. 闭合计划（需要在 Tony 的 Mac 上跑只读查询）

不改任何代码，只写一个**只读**的对账脚本：对 6/24–7/17 这 18 天，用数据库原始行情把每个 OPEN/PARTIAL 指标的**候选公式变体**都算一遍，和昊哥的数字逐个比对，选出能 18/18 吻合的那一个。

| 指标 | 要比对的变体 |
|---|---|
| M01/M02/M03 | 全市场 / 主板；含 / 不含 ST；含 / 不含北交所 |
| E02/E05 “大面” | 收盘 ≤ -5% / 收盘 ≤ -7% / 高点回撤 ≥ 10% / 收盘 ≤ -9.5% |
| E03 | 分母为昨日连板 / 今日连板；主板 / 全市场 |
| E04 | 主板连板数之比 / 全市场之比；连板的定义是否包含一字板 |
| X03 | 主板 / 全市场 |

**验收（机械判定）**：
- 每个指标找到一个与 18 天数字吻合的变体（容差 ±0.01，计数 ±1）→ CLOSED；
- 找不到的保持 OPEN，并且**不进入实现**。

**禁止**：按日期打补丁、单日人工覆盖、合成兜底值。
