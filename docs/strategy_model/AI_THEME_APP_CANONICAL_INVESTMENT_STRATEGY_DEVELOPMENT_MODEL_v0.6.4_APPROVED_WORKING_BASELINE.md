# Part 1 — 模型分层

```text
L0  证据与来源
L1  大环境（Global Market Environment）          ← 风浪多大
L2  题材与主线身份（Theme & Mainline Identity）    ← 哪个方向
L3  主线周期（Mainline Lifecycle）                 ← 这道浪走到哪一段
L4  共振择时（Timing Resonance = L1 × L3）         ← 现在值不值得出手
L5  强势股与角色（Strong Stock & Role）            ← 上哪条船
L6  策略路由（Strategy Router）                    ← 允许跑哪种战法
L7  战法 Setup（1进2 / 弱转强 / …）
L8  预期（Expectation：次日应该看到什么）
L9  确认（竞价 / 开盘 / 盘中）
L10 决策（WAIT / PROBE / ENTER / ADD / HOLD / REDUCE / EXIT）
L11 仓位与风险
L12 复盘与学习
```

## 2.3 结构化理解

- [S] 大环境不是一个分数，而是**当天的风险许可**：决定今天能不能出手、用突破还是低吸、仓位放多大。依据是 CS-03 p2 的三句话（盛极而衰不做龙头；好突破、差低吸；高胜算胆大、行情差谨慎）。
- [S] 大环境至少包括三个方面：
  - **短线接力生态**：涨跌停、晋级、昨日涨停今日的表现；
  - **指数状态**；
  - **外部和宏观信息**（A50、汇率、外盘）。
  
  依据是 CS-03 的盘前清单和信息源。
- [S] 外部参考（EXT-01）：昊哥的“大盘势能 + 情绪动能”是一套成熟的短线接力生态读数。60 天复现验证中，投票结构成立（势能 58/60、动能 60/60），说明大环境这一层**可以量化**。但它是外部参考模型，用来校验我们的读数，不替代 Tony 的定义。

## 3.3 事件 → 题材 → 个股链（题材研究方法）

[E] CS-11/12/09 的写法是固定结构：
1. **消息面驱动**：逐条列事件，标明新闻来源。
2. **投资机会表**：个股、题材正宗性、板块、资金性质、流通性质、技术形态、是否次新、龙头属性（龙头 / 龙二 / 套利 / 补涨 / 卡位 / 助攻）。
3. **未证实的消息**明确标“网传 / 未证实”。

[E] CS-10 的写法是产业链图谱：AI → 国产算力（服务器：液冷、供电）→ 芯片制程（光刻机、光刻胶、洁净室）→ 国产芯片（芯片设计、AI 芯片）。

[S] 因此题材研究分成三步：事件（有来源、可信度）→ 题材（逻辑：新、时、广）→ 个股（正宗性 + 市场属性 + 角色）。依据：CS-03 p1 的五类来源与三项逻辑评估，加上 CS-09、CS-11、CS-12 的“消息面 → 投资机会表”写法。

**以下两条是工程/本体提案 [P]，不是 Tony 原始策略语义：**

- [P] **题材类型本体**：行业类、事件类、政策类、叙事类、风格类；题材可以有多个上级；股票与题材的归属关系随时间变化。
  - 原文能支持的只是**催化来源的五类**（政策、技术创新、重大事件、行业周期、资产重组，CS-03 p1）。那是“东风从哪里来”的分类，不是“题材是什么类型”的分类。
  - 这个提案的动机来自外部案例：“厄尔尼诺”同时带动农业和电力，“华字辈”横跨陶瓷、传媒和出版（EXT-01，9 月）。外部案例只能说明需要这种表达能力，不能把它升级成 Tony 的策略。
- [P] **题材 ≠ 周期片段**：同一个题材可以先后走几段独立的周期。
  - 原文写到“周期结束 → 混沌期”（CS-02），但没有说同一题材能不能重新开一段周期。
  - 外部案例：EXT-01 中的医药，6/23–7/16 一段，8 月由哈药带出“二波”。是一个片段还是两个片段，见 THEME_CATALOG 的待定问题。

## 3.4 主线身份的状态（[P] 命名）

```text
UNKNOWN → CANDIDATE（有催化、有初步市场响应）→ CONFIRMED（逻辑 + 市场两个维度都成立）
          ↘ STRONG_HOTSPOT（市场强，但逻辑级别小；“强热点”一词见 CS-01、CS-04）
          ↘ NON_MAINLINE（市场不认可：“逻辑成立但市场不相信、没有持续性的，也要果断放弃”，CS-03 p1）
CONFIRMED / STRONG_HOTSPOT → EXPIRED（身份本身失效；与片段 ENDED 不同，见 OP-18）
```

**v0.6.1 删除了 DEGRADED。** 原因：它很容易被实现成“主线一分歧，身份就降级”，等于把 L3 的正常分歧重新写进 L2，正是 v0.5 犯过的错。

- “主线今天变弱了”由 L3 周期（DIVERGENCE、FADE）和相对强度来表达，**不改变身份**。
- **EXPIRED** 只表示身份本身失效：催化逻辑被证伪，或者市场对这个方向的认可持续消失。周期进入 FADE 或 ENDED，**不自动等于** EXPIRED。两者是什么关系，见 OP-18。

## 4.2 原文中的周期序列（共四处，都保留）

**CS-02（市场情绪周期.key）**：
```text
混沌期 → 初期（新题材刺激，部分个股领涨，犹豫观望）
→ 发酵（资金认可题材，高关联个股开始上涨）

→ 弱转强（情绪分化，买入力道大于卖出，由冷转热）

→ 分歧 → 退潮（股价加速下跌，恐惧）→ 周期结束 → 混沌期
```

**CS-03 p2 “情绪轨迹”句**（v0.6.3 补登。之前各版都漏了这一句，见 Part R 的 M-11）：
```text
市场初期（犹豫，试探性买入试错）→ 市场发酵（股价开始上涨，开心）

→ 周期结束（市场重新进入犹豫、观望），周而复始
```
原文用的是“市场”二字，但写在“看市场情绪（30%）· 找准切入周期”之下，紧接着的各阶段特征又是按板块写的（“板块集体高潮”“板块内出现首个 3 连板”）。所以 [S] 它描述的是**主线 / 题材周期**，也就是核心公式里占 30% 的“情绪”，不是 L1 大环境。

**CS-03 p2–3 阶段操作表**：


**CS-09（A股题材&强势股跟踪，每日模板）**：
```text
按题材逐个判定：是否属于主线 / 启动 / 发酵 / 分歧 / 弱转强 / 高潮 / 退潮 / 当日涨停数 / 结论
```
这一处只是一组**阶段名称**，没有给出顺序，所以只能支持“有哪些阶段”，不能支持“阶段之间怎么走”。

[S] 这几处资料不是互相否定，而是描述了**几种都会出现的路径**：
- 直线路径：初期 → 发酵 → 加速 → 高潮 → 分歧 → 退潮（CS-03 情绪轨迹）；
- 先加速、再分歧、再修复、最后高潮（CS-02）；
- 先高潮、再分歧、再修复，然后再次高潮（CS-03 操作表）。

所以周期应当画成**状态图**，而不是一条流水线。

## 4.3 作用域：“混沌期”不是单个题材的状态

v0.6 把 CHAOS 放进了题材周期的状态图（ENDED → CHAOS → EARLY）。这是作用域混用：

- 原文的“混沌期”，描述的是**整个市场还没有形成清晰主线、在等新题材**（CS-02 “周期结束 → 混沌期”；CS-03 p1 “新题材出现在市场低潮混沌期时，成为主线的可能性越大”；CS-08 p3 “题材分散、没有主线时容易走不远”）。
- 它不是“医药这个题材现在处于混沌”。医药这段周期结束，就是**医药这一段 ENDED**。

所以 v0.6.1 拆成两个对象：

| 对象 | 作用域 | 取值 | 标记 |
|---|---|---|---|
| **主线格局**（Mainline Landscape） | 交易日（全市场） | `NO_ACTIVE_MAINLINE`（混沌期）/ `HAS_ACTIVE_MAINLINE` | 概念 [S]；命名 [P] |
| **题材周期**（Theme Lifecycle） | 交易日 × 题材周期片段 | EARLY / FERMENTATION / ACCELERATION / CLIMAX / DIVERGENCE / REPAIR / CATCH_UP / FADE / ENDED | 阶段 [E]（CS-02、CS-03、CS-09）；命名 [P] |

- [S] 主线格局由全部题材的身份与周期**汇总得出**，不是独立观测出来的量。它也**不是 L1 大环境**：没有主线不等于风险高，冰点也不一定没有主线。原文“低潮混沌期”把两件事写在了一起，本模型把它们分开记录。
- [P] 一个题材在任何周期片段之外时，**没有周期状态**（不是 CHAOS）。片段从 EARLY 开始，到 ENDED 结束。

## 7.3 弱转强（CS-05、CS-01、CS-03）

**核心思想**（CS-05、CS-01）：**该弱不弱则为强。**

| 环节 | 原文 | 出处 |
|---|---|---|
| 定义 | 龙头在高位分歧后看似走弱，但第二天（或极短时间内）通过强势反包、放量涨停重新夺回市场话语权；本质是主力洗盘震仓后再次合力进攻，往往意味着二波或高度延伸 | CS-05 p1 |
| 资格 | **一定要是强势股或龙头，跟风杂毛不配弱转强**；龙头才有弱转强价值，跟风股大概率“反抽即死” | CS-05 p4；CS-01 |
| 三种“弱” | 连板过程中出现中到大阴线；冲高回落留上影；烂板涨停 | CS-05 p1 |
| 分歧日的条件 | 收盘时仍有资金护盘，价格守住关键支撑（5 日、10 日线，或前一日涨停价附近） | CS-05 p1 |
| 烂板“烂而不弱” | 涨停在箱体突破位或前高；放量释放套牢盘；炸板；破板后不大跌、在均线之上震荡、回撤 3% 以内；烂板封单少于正常、下跌缩量 | CS-05 p2 |
| 板块 | 题材情绪没有全面退潮，仍有资金支撑；板块内有其他个股异动，尤其是补涨助攻 | CS-05 p1–2 |
| 次日的转强类型 | 集合竞价弱转强（高开或抢筹）；早盘分时弱转强（不单边下跌、放量拉升、大部分时间在均价线上）；盘中弱转强（由弱于大盘变成强于大盘；从均价线下回到线上；突破半小时以上的分时平台） | CS-05 p2–3 |
| 关键位置 | 前一日分时低点不破；关键均线支撑有效；成交量不能明显萎缩，否则是假反抽 | CS-05 p4 |
| 买点 | 回踩承接确认后打板或半路；低开 → 震荡 → 突然直线拉升封板；反包前高；回踩 5 日、10 日线后放量突破；分时均线支撑处放量上攻；反包涨停瞬间 | CS-05 p4 |
| 真假辨别 | 真：放量换手、封单坚决、次日承接良好；假：缩量拉升、封单虚弱、次日冲高回落 | CS-05 p4 |
| 仓位 | 首次尝试 1–2 成；主线 + 绝对龙头可以加大到 5–8 成；龙二 / 次龙头 2–4 成；信号确认后可加到中等仓位；切忌满仓 | CS-05 p4 |
| 止盈止损 | 反包失败、当天不能重新站上关键价位 → 减仓或止损；反包成功后持股待涨，等二波或加速；日线跌破 10 日线或前低 → 立刻减仓或清仓 | CS-05 p4 |
| 环境 | 大盘极度退潮时成功率极低；适合“分歧 - 修复”阶段，不适合“全面退潮” | CS-05 p5 |
| 心态 | 容易被假动作诱多，要快速反应；不贪最低点，抓确认信号更安全 | CS-05 p5 |
| 体系层面的补充 | 大环境好时龙头分歧绝不能买；大环境不好的被动分歧，承接好、收盘守住关键点位、换手 <50% 时可以买；分歧下跌当天尽量不要低吸 | CS-03 p3 |

**结构化补充**：
- [S] 弱转强是**三层共振**：大环境允许修复 × 主线从分歧走向修复 × 龙头个股由弱转强。竞价、均价线、承接、放量和封板只是最后的触发证据。
- [S] “前一日分时低点不破”在原文里是**买入前**的护盘条件；已经持仓之后的退出依据，是“反包失败”和“日线跌破 10 日线或前低”。两者不能混用。

## 9.1b 持仓管理的原则（OP-08，[O] 拟定）

```text
战法（Setup）          决定怎么进
角色 + 周期            决定怎么拿
失效条件（Invalidation） 决定什么时候必须走
```

持仓按**当前**的角色和周期管理，不按当初用的战法。用 1进2 买入后：
- 如果升级为龙头，且题材进入发酵或加速，就转为龙头持有管理；
- 如果没有升级，继续执行 1进2 的退出纪律。

失效条件触发时，不管当前角色是什么，都必须执行。

## 9.3 退出的归类 [S]

按原因分为六类，原文均有依据：
1. **战法前提失效**：假弱转强；弱转强的再一致窗口过期。
2. **大盘或题材终局退潮**：“退潮 - 放弃”。
3. **结构破坏**：止损位被击穿；日线跌破 10 日线或前低。
4. **执行失败**：炸板封不回；10:30 前不封板。
5. **预期偏离**：高开 7–8% 后回落；低开后冲高回落。
6. **阶段止盈**：高潮必要时止盈；再次高潮止盈离场。

# Part 13 — 工程原则（[P]，供 Freeze 之后的架构审计使用）

这些不是策略本身，是把策略机器化时必须守住的边界：

1. **层次分离**：大盘环境、主线身份、主线周期、角色、战法，各自独立成状态；不共享同一个状态机，不混用词汇。
2. **状态不是分数**：状态由“前一状态 + 当天证据 + 变化方向”推出；禁止用加权总分直接映射阶段，或直接生成买入。
3. **研究单位**：大盘层按交易日；主线层按“交易日 × 题材”；题材和周期片段是两个对象。
4. **证据可信度**：每个观测值要标明是实测、推导、估算还是缺失；估算和缺失不能参与正式判断。
5. **防止用到未来信息**：系统判断只用当时可见的证据；事后标签与当时判断分开保存。
6. **T+1 约束**：当天买入、当天触发的离场，只能在次日执行。
7. **外部模型的定位**：昊哥的量化只作为大盘环境的参考模型，不作为 Tony 策略的来源。
8. **来源编号不可变**：canonical Source ID 一经分配不再重新编号；编号和权威等级分开记录。
9. **规则追溯到边和格**：周期转移要能追溯到 §4.5 的边编号，大盘相关规则要能追溯到 §5.1 的 R 编号和作用域组（A–E）；追溯不到的输出 BLOCKED_UNDEFINED，依赖未冻结政策的输出 BLOCKED_POLICY_UNFROZEN，**都不能写成 WAIT**（§5.7）。
10. **作用域不混用**：全市场的“主线格局”（有没有主线）、L1 大环境（风险高低）、单个题材的周期，是三个不同的对象；“大盘影响交易”的规则按 A–E 五组分开，只有 B 组叫共振。
11. **来源四维度不合并**：ID、canonical tier、作者、能否定义 Tony 策略，分开记录（§0.2）。
