🔍 问题分析：

在 App.tsx 中，路由匹配逻辑是：

if (path.startsWith("/collection")) {
    return <CollectionPage />;
}
// ... 其他路由
return <IntelPage />; // 默认

⚠️ 这意味着：

  • 访问 /collection → 看到 CollectionPage（日采集控制台）
  • 访问 /collection/anything → 看到 CollectionPage
  • 访问 /collections → 看到 IntelPage（情报台）
  • 访问根路径 / → 看到 IntelPage（情报台）
