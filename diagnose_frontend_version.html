前端版本诊断工具

诊断前端代码是否已更新

诊断步骤

  1. 打开选股器页面: http://localhost:5173/screener
  2. 按 F12 打开开发者工具
  3. 在Console标签中运行以下命令：
// 检查前端代码版本
console.log('=== 前端代码版本诊断 ===');

// 方法1: 检查页面中是否有调试日志
console.log('检查方法1: 查看最近的控制台输出');
console.log('如果看到以下日志，说明代码已更新:');
console.log('  🔍 StockScreenerPage - store状态变化 (时间戳: ...)');
console.log('  🔍 executeScreening开始: selectedStrategyId=');
console.log('  🔍 API响应 (时间戳: ...):');

// 方法2: 检查React组件
console.log('\n检查方法2: React组件状态');
console.log('如果有React DevTools扩展:');
console.log('  1. 打开React DevTools');
console.log('  2. 找到 StockScreenerPage 组件');
console.log('  3. 检查 props 和 state');

// 方法3: 直接测试API
console.log('\n检查方法3: 直接测试API');
console.log('在控制台运行以下代码测试API:');
console.log(`
fetch('http://localhost:8003/api/stock-screener/execute', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        strategy_id: 'default_composite',
        trade_date: '2026-04-10',
        limit: 3,
        enable_llm_review: false,
        llm_top_k: 3
    })
})
.then(r => r.json())
.then(data => console.log('API响应:', data))
.catch(err => console.error('API错误:', err));
`);

console.log('\n=== 诊断建议 ===');
console.log('如果看不到调试日志，需要:');
console.log('1. 强制刷新: Ctrl+Shift+R (Win/Linux) 或 Cmd+Shift+R (Mac)');
console.log('2. 清除浏览器缓存');
console.log('3. 重启前端开发服务器');

强制刷新指南

如果诊断显示前端代码未更新：

  • Windows/Linux: 按 Ctrl+Shift+R
  • Mac: 按 Cmd+Shift+R
  • Chrome: 右键刷新按钮 → "清空缓存并硬性重新加载"
  • Firefox: 按 Ctrl+F5 或 Cmd+Shift+R

或者清除浏览器缓存：

  1. 按 F12 打开开发者工具
  2. 切换到 Application 标签 (Chrome) 或 Storage 标签 (Firefox)
  3. 点击 Clear storage 或 Clear site data
  4. 勾选所有选项，点击 Clear site data

重启前端开发服务器

如果强制刷新无效，可能需要重启前端开发服务器：

# 在终端中执行
cd /Users/admin/Desktop/ai_theme_app/frontend
# 停止当前服务器 (按 Ctrl+C)
# 重新启动
npm run dev
